# Работа над TestPilot 1C

Используйте существующий checkout. Каждая облачная задача уже изолирована; не создавайте Git worktree без явного запроса пользователя. Не публикуйте код и не отправляйте коммиты в remote без разрешения.

UI и документация — на русском. Основной сценарий: две нормализованные JSON-версии → impact API → HTTP-пакет → intelligence API → объяснимый план. Источник истины результатов — PostgreSQL; второй сервис не читает таблицы impact.

Подтверждённого подключения к 1С в облаке пока нет. Пользователь уточнил: доступной публикации с веб-клиентом и OData сейчас нет. Не пытайтесь проверять OData/Vanessa/EDT без предоставленных доступа и образцов; не заменяйте реальный запуск автоматически созданными passed. Демо загружается только явно в demo-sales или presentation-sales, с synthetic=true.

Точные команды — README. Пароли — только локальный игнорируемый .env / переменные окружения. Не выводите значения в логи, чат или артефакты. `scripts/local_env.py` сохраняет существующий .env. Миграции — Alembic, не создавайте таблицы при старте приложения. Новое изменение схемы — отдельная ревизия.

Перед ответом выполняйте подходящие pytest-проверки с PostgreSQL. Для изменения сквозного потока — `scripts/smoke.py`; для UI — `scripts/browser-smoke.py` при наличии Playwright/Chromium. Отделяйте реальную проверку от предположений, синтетические замеры от производственных гарантий. Не стирайте volume ради повторной загрузки демо.

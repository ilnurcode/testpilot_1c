# Следующие этапы после MVP

Текущая реализация и фактические проверки описаны в validation.md. Это список развития, а не скрытые условия успешного учебного сценария.

1. Реальная интеграция:
   - [x] Реализован парсер XML/EDT выгрузок 1C (`XMLEdtAdapter`).
   - [x] Реализован прямой разбор бинарных расширений CFE, обработок EPF, отчётов ERF и конфигураций CF (`V8Container`, `Binary1CAdapter`) с анализом директив расширений (`&Вместо`, `&Перед`, `&После`, `&ИзменениеИКонтроль`).
   - [ ] Подключение внешнего BSL Language Server для глубокого статического анализа модулей.
2. Runner и физическая интеграция с 1С:
   - [x] Реализован клиент стандартного OData 1С (`ODataClient`) с белым списком таблиц.
   - [x] Реализован раннер веб-клиента Playwright (`WebClientRunner`) с авторизацией и фиксацией скриншотов.
   - [x] Проведено тестирование против физической базы DemoEnterprise20 на Apache 2.4 / 1С 8.5.
   - [ ] Запуск сценариев на промышленном контуре с серверной лицензией 1С (снятие ограничения лицензии разработчика на одновременные сеансы).
3. Производственные права: индивидуальные пользователи/SSO, HTTPS, ограничение подбора пароля, отдельные DB-роли и grants.
4. Масштаб: фоновые задачи, общий лимит CPU/памяти, полный обход для длинных цепочек, контролируемое усечение объяснений без усечения достижимости, более сильная оптимизация большого каталога.
5. История: настраиваемое окно, исторические снимки каталога и состояний дефектов, строгие связи между версиями/запусками, CSV-импорт.
6. ML: реальная временна́я выборка и метрики пилота, защита от изменений статических атрибутов в прошлом, drift и повторное обучение.
7. UX: визуальный редактор карточки вместо JSON, отображение базового/целевого графа вместе, локализация машинных enum, поиск и пагинация больших каталогов.
8. Публикация облачной среды выполняется пользователем. Восстановление в новой задаче и на иной машине отдельно ещё не подтверждено.
9. Локальный Windows Docker Compose запускается двойным щелчком; реальные сети/Docker Desktop сборка в облачной среде не подтверждена из-за отсутствия DNS внутри Docker build. Повторить сборку на машине пользователя с Docker Desktop и доступом к пакетным реестрам.

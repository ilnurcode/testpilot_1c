# Демонстрационное расширение 1С (уязвимости и дефекты v8std)

Данное расширение подготовлено для демонстрации статического анализатора и проверок стандартов **TestPilot 1C**.

## Заложенные дефекты:
1. `v8std:managed-lock-in-posting`: Проведение без явной БлокировкаДанных в `ОбработкаПроведения` (`ObjectModule.bsl:7`).
2. `SEC001`: Опасный динамический вызов `Выполнить()` со строковой конкатенацией (`ObjectModule.bsl:34`).
3. `SEC002`: Инъекция в текст запроса 1С через конкатенацию `+ КодТовара` (`ObjectModule.bsl:19`).
4. `v8std:virtual-tables-params`: Виртуальная таблица `.Остатки()` без параметров с отбором в секции `ГДЕ` (`ObjectModule.bsl:25`).
5. `v8std:hardcoded-credentials`: Хардкод пароля/токена шлюза `SecretTokenKey_2026` (`ObjectModule.bsl:37`).
6. `v8std:server-in-client-loop`: Вызов сервера в цикле на клиенте `&НаКлиенте` (`Module.bsl:4`).
7. `v8std:unconditional-server-context`: Директива `&НаСервере` вместо `&НаСервереБезКонтекста` (`Module.bsl:24`).
8. `v8std:empty-exception-handler`: Пустая секция `Исключение` (`Module.bsl:17`).
9. `v8std:naming`: Однобуквенная неинформативная переменная `с = 100;` (`Module.bsl:11`).
10. `v8std:privileged-mode`: `УстановитьПривилегированныйРежим(Истина)` без проверки прав пользователя (`CommonModules/ИнтеграцияСлужебный/.../Module.bsl:8`).
11. `v8std:query-in-loop`: Выполнение запроса внутри цикла (антипаттерн N+1) (`Module.bsl:18`).
12. `SEC005`: Запуск внешней команды ОС `КомандаСистемы("curl ...")` (`Module.bsl:11`).

## Как проверить в TestPilot 1C:
1. Откройте веб-интерфейс TestPilot 1C:
   Перейдите в раздел меню **«Аудит и стандарты v8std»**.
2. Переключитесь на режим **«Каталог / Расширение»** и укажите путь:
   `samples/demo_vulnerable_extension`
3. Нажмите кнопку **«🔍 Запустить аудит v8std»**.
4. Все дефекты мгновенно отобразятся с номерами строк, исходным кодом и пояснениями стандартов v8std!
